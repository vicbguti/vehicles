# Solution Variables Visualizations

This directory groups analytical visualizations and mapping charts of modeling variables, organized into two categories:

## Spatial

* **[Class Distribution](./spatial/class_distribution.md)**: Physical capacity and class group counts.
* **[Geographic Demands](./spatial/geographic_demands.md)**: Spatial coordinates and destination mappings bubble map.

## Temporal

* **[Temporal Trends](./temporal/temporal_trends.md)**: Seasonality and time-series registration patterns.
* **[Temporal Trends Per Class](./temporal/temporal_trends_class.md)**: Class-specific monthly demand registration patterns.
* **[Temporal Trends Per Location](./temporal/temporal_trends_location.md)**: Location-specific monthly demand registration patterns.
* **[Combined Temporal Trends](./temporal/temporal_trends_combined.md)**: Class-and-location monthly demand registration patterns.
